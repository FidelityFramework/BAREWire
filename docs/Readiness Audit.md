# Readiness Audit and Build Plan — 2026-09-03

This document sets the table for building BAREWire's memory mapping model and platform description, so that the applications now carrying those concerns by hand — WrenHello, HelloArty and the Arty A7 platform tree, the Linux x86_64 platform tree, Conclave — can be re-based onto the library. The design documents in this folder are the specifications the build proceeds from. [Implementation Status](./Implementation%20Status.md) remains the ledger of what exists; this note is the plan for closing the distance between the two, ordered by what binds what, with the application gaps each step closes named beside it.

## 1. The mission the build serves

**Primary.** BAREWire is the typed contract between Clef components: a value crossing a BAREWire boundary preserves its case structure, payload types, and dimensional annotations by construction ([Substrate_Formalism](./Substrate_Formalism.md)). Read inward, it is the declared authority on memory layout for every processor a program runs on ([11 Platform Description](./11%20Platform%20Description.md)).

**Secondary.** The same contract binds to JavaScript, .NET, Rust, C, and C++, in two modes. A **source-shared contract** is one protocol file compiled by Fable, .NET, and Composer; the types are the contract. This is demonstrated: WrenHello's `src/Shared/Protocol.fs` compiles unmodified under Fable and Composer by inclusion in two project files, and Conclave's `Conclave.Protocol` extends it to three compilers. A **schema-shared contract** is a BARE schema as the interchange artifact where source cannot be shared; each language's codec is generated from it. The source-shared mode is the earlier phase and the one the WREN stack depends on now; it is designed first and firmest, and the schema-shared mode is designed to degrade to the same envelope and encoding.

**Two extraction sources.** WrenHello holds the bridge facets. The Arty A7 platform tree holds the declared-platform facets. Both are extracted and abstracted into this library; neither is re-invented.

## 3. What exists to build from

**Specifications in this folder.** [04 Memory Mapping](./04%20Memory%20Mapping.md) specifies Region and View, address calculation, and Farscape integration. [08 Hardware Descriptors](./08%20Hardware%20Descriptors.md) specifies peripheral, field, bitfield, and struct descriptors; its "Unified Memory Description" section is the seed 11 grows from. [11 Platform Description](./11%20Platform%20Description.md) specifies the platform value — memory spaces with capacities and orderings, buffer schemas with capacity and framing, boundary surfaces with declared contracts, transports — and the three observers (emission, constraint generation, obligation generation). [03 Schema System](./03%20Schema%20System.md) specifies schema definition, validation, and compatibility. [02 Encoding and Decoding Engine](./02%20Encoding%20and%20Decoding%20Engine.md) specifies the BARE codec. [05 Network Protocol](./05%20Network%20Protocol.md) and [06 IPC Integration](./06%20IPC%20Integration.md) specify framing and transports and carry more than one envelope between them; the build adopts one (§4 step 3) and the documents are brought to it. [Arena_Design](./Arena_Design.md) is the authoritative design of an allocator that already lives in CCS as an intrinsic. The code samples in these documents predate the move to Clef and use BCL calls (`Guid`, `BitConverter`, `DateTimeOffset`, `Span`) that the implementation will not; they are read for the design, and the implementation follows [99](./99%20Elminating%20Dotnet%20Dependencies.md) and the Clef surface.

**Source in this repository** (as of the 2026-09-03 rebuild; the paragraph that stood here described the FNCS-era tree, since deleted). Six tiers under `src/`, one source for three project files: `Encoding/` (the BARE codec over bounded extents, with per-substrate shims), `Framing/Envelope.fs` (the adopted envelope), `Schema/` (BARE's fixed vocabulary, validation, analysis, `.bare` emission), `Hardware/` (descriptors, ABI profiles, the layout validator, BTF), `Memory/` (Region and View), `Platform/` (the description and its three observers). `tests/` is the .NET gate and the JavaScript differential; `samples/RoundTrip` is the native gate. [Implementation Status](./Implementation%20Status.md) is the ledger; [12](./12%20Intersection%20Subset.md) records the compiler-surface rules the source follows and the gates. The test project that referenced a deleted `src/Core/` and the provider design of `tests/Platform/Providers/` are gone.

**Working code outside this repository.**

- `Conclave/src/Wire/Conclave.Wire`: `Bare.fs` (Writer and Reader over `byte[]`, ULEB128, zigzag, fixed-width little-endian; no Span, no BitConverter, no reflection; Fable and .NET), `Envelope.fs` (kind u8 Tell/Ask/Reply/Event/Control, correlation u32 LE, BARE payload, u32 length prefix on stream transports, five constructors), `Codecs.fs` (per-union module functions and `encodeWith`/`decodeWith`), with round-trip tests. Written to be absorbed here.
- `Conclave/src/Client/.../Bridge.fs`: the transport half alone, 22 lines, Base64 on the script-message channel.
- `WrenHello/src/Shared/Protocol.fs` and the two `Codec.fs` files; `Backend/Main.fs` for the transport (`dlsym` on the dotted symbol, `evaluate_javascript` with explicit length, the slot-buffer `user_data` idiom).
- `Fidelity.Platform/Contracts/PlatformContracts.clef` (endpoint vocabulary; every tag is a string alias with a constant module because Composer's cross-assembly DU layout import fails — every type this build proposes must clear that wall the same way) and `FPGA/Xilinx/Artix7/ArtyA7_100T/ArtyA7_100T.Bindings.clef` (60 pin records, clock, internal POR reset, device part).
- `Composer/src/MiddleEnd/PSGElaboration/PlatformPinResolution.fs`: structural extraction of declaration records from the PSG by type name and field name (substrate-neutral; only the four `extract*` functions are FPGA-shaped); `Coeffects.fs:222-284` (`PlatformPinMapping`, "two observers, one truth, two residuals"); `Alex/Traversal/XDCTransfer.fs` (72 lines, pure coeffect to constraint text — the template for every constraint residual); `SMTTransfer.fs` (already cites `XDCTransfer` as its model); `FrontEnd/Templates/TemplateTypes.fs` (an orphaned `MemoryRegionDef` shape, the input to the memory-space type).

- `Fidelity.Platform/docs/CANONICAL_PLATFORM_SPEC.md`: diagnoses the two competing descriptor schemas in the CPU tree and confirms the FPGA path reads plain records structurally, not quotations. Its `TargetCore` block is a sub-record of the platform value, not a parallel schema.

## 4. Build order

Steps are ordered by what binds what. Each names its specification, its inputs, and the gap it closes.

1. **Build scaffold.** A `[compilation] target` in `BAREWire.fidproj`; a `.fsproj` for the portable tier; the dual compile real: the Encoding tier and the envelope compile under Fable, .NET, and Composer from one source, written in the intersection subset (§5). Nothing below is testable without this. Independent of every other step.
2. **Encoding tier complete.** Recover the encoder from `3182359`; replace `IBARECodec<'T>` with module-function combinators (`Conclave.Wire/Codecs.fs` has the shape); settle the Fable-side UTF-8 and DataView shims. Spec: 02. Closes: Conclave W-05's precondition.
3. **The envelope.** Adopt one: Conclave's is the candidate (five bytes on a self-framing transport; length prefix only on stream transports; schema epoch as a `Hello` control frame; no magic or version bytes because the schema is fixed at compile time on both ends). Bring 05 and 06 to it. Spec: 05, reconciled. Closes: WrenHello's three-way message kind and missing correlation; Conclave's stand-in envelope.
4. **Golden-frame corpus and differential gate.** Byte-exact vectors per schema type that every implementation must pass, and a differential test where two implementations meet on one wire — first the client UI (Fable) to native host (Composer) bridge. This is the cross-substrate byte-identity claim made testable.
5. **`StructDescriptor` validator.** Descriptor plus target ABI in, agreement verdict out. Implementation Status names it the first real code; it exercises the §7.3 question (Fixed versus Resolved dimensions at a boundary) on a concrete case. Spec: 08, 10. Closes: Farscape's ABI-wrong bindings, HelloWayland's hand-padded descriptors.
6. **Region and View.** The mapping half over the portable byte model and the native memref. Spec: 04, with 09 for alignment and cache-line facts. Inputs: the Encoding tier, the validator. The JavaScript realization is a view over `ArrayBuffer` with offset and length — the same bounded-extent discipline with no addresses — which is the test that the abstraction is not hardware-shaped.
7. **The bridge extraction (WrenHello → BAREWire).** Module boundaries: `Contract` (the shape a protocol project satisfies, and the discipline rules; declarative), `Encoding` (value ⇄ payload bytes; per-union module functions; no framing knowledge), `Framing` (payload ⇄ frame; kind, correlation, optional length prefix; no medium knowledge), `Wrapping` (frame ⇄ medium unit; identity for a WebSocket binary message, Base64 for a script-message string), and `Session` (correlation allocation, pending-ask table, epoch handshake, rejection policy). Changing transport touches `Wrapping` and nothing else. Stays in Fidelity.Platform: the WebView host operations in the shapes finding 9 requires, the callback boundary, the length-carried-string rule as a Platform obligation, the RFC 6455 server, the weld. Correct 07 line 91 (script messages today, WebSocket next). Closes: every WrenHello row in §2; Conclave W-01 through W-04.
8. **`[<BAREWireSchema>]` consumer in clef**, mirroring `extractPinAttribute` (`clef/.../Expressions/Types.fs:678`), so a schema travels in the type the way a pin name does. Closes: the zero-consumer attribute on `HelloArty/src/Shared/Contract.clef`.
9. **Platform description types, and the Arty description with memory.** Types under `src/Platform/`: `MemorySpace { Name; Kind; Capacity; Alignment; Ordering; Access; Base option }` with kinds extending `Hardware.MemoryRegionKind` (`BlockRam`, `DistributedRam`, `Registers`, `Stack`, `Arena`, `Rodata`, `ViewBacked`, `PersistentStore`, `NeuronState`); `BoundarySurface { Name; Kind; Endpoints; Defaults; Contracts }` with `Endpoint.Location` as `PackagePin | SyscallNumber | GlobalPath`; `BufferSchema { Name; Schema; Capacity; Framing; Space; Lifetime }` with `Framing = Fixed | LengthPrefixed | Delimited | Capped`; `Transport { Name; Endpoints; Rate; MaxUnit; Ordering; Schema }`; `LifecycleFacts { Clocks; Resets; Entry; Teardown; Persistence }`; `PlatformDescription` over them. All tags string-aliased with constant modules (the DU-import wall). Then the Arty value: the 60 pins re-homed with `LVCMOS33` as a surface default; BRAM and register memory spaces with capacity and granularity (new content, and it forces the vocabulary against the target that cannot be lied to); the UART TX buffer schema for `ArtyReport` with capacity and framing; the UART transport at `DefaultBaud`; clock and POR reset as lifecycle; `clockHz` and `ticksPerMs` derived. `Contracts/PlatformContracts.clef` becomes an alias layer over the BAREWire types so no leaf breaks. Spec: 11, 08. Closes: every Arty row in §2, and `UartReport` stops being `ValueNone`.
10. **Generalize `PlatformPinResolution` into platform-description resolution.** Same structural extraction; a type-name table instead of four hard-coded cases; no silent `None` on a missing clock or device; `PlatformPinMapping` becomes the FPGA projection of a general layout coeffect; `MLIRGeneration.fs:86-90` loses its FPGA gate so every target resolves its description and each backend projects what it needs. `FrontEnd/Templates/` is deleted. Closes: the duplicated and unread platform facts in the fidproj files.
11. **The Linux x86_64 description.** Memory spaces (rodata, text, data/bss, stack with a declared rlimit, arena with the bump discipline from Arena_Design, heap); the syscall table as described interfaces with contracts (`read`: writes at most `count` bytes into `buf`, returns `n ≤ count`, `n = 0` is EOF); `consoleReadln { Capacity = 1024; Framing = NewlineTrimmed; Space = arena }` so `PlatformPatterns.pSysReadline` observes the declaration instead of authoring `1024L` and the unconditional `-1`; the `SockAddrIn`/`PollFd`/`EpollEvent` comment layouts as schemas with a declared padding policy; transports (WebSocket, Wayland, the `pilot/*.toml` surfaces); entry, sections, and page permissions as lifecycle. `CANONICAL_PLATFORM_SPEC.md`'s `TargetCore` is the identity sub-record. Closes: every Linux and HelloProof row in §2.
12. **The V8 isolate description** (Cloudflare Worker), written by the Conclave side against the same types: `ViewBacked` memory (ArrayBuffer views, no addresses); DO storage as a persistent space with declared capacities; WebSocket as a message-framed transport with a hard cap so an over-cap message is a compile-time obligation; hibernation and eviction as lifecycle. Closes: Conclave's capacity and lifetime gaps; proves the vocabulary is not hardware-shaped.
13. **The CPU's constraint residual.** A linker script or memory-map manifest emitted from the Linux description, as `XDCTransfer` emits XDC from the Arty one; `ProofObligations.fs` as the third observer, citing `BufferSchema` names instead of restating constants. Spec: 11 ("declared, directed, then confirmed"). Closes: HelloProof's rodata finding.
14. **Schema-shared generation.** A `.bare` schema emitted from a Clef type, and codec generation from a schema for the languages that cannot share source; the F# side's per-union codecs become generated output. Spec: 03, extended with the interchange story it does not yet carry.
15. **Measures on the wire.** Dimensional annotations carried in frames; settled at the type-theoretic level (NTU), absent in source. Last, because it rides everything above.
16. **The kernel description vocabulary.** The additions [11](./11%20Platform%20Description.md) §"The kernel as a described platform" names, so that a `BPF/Linux/6.x` leaf and a ThreeBody frame schema can be written in Fidelity.Platform without extending the types again: version-ranged availability on endpoints, memory spaces, and transports; Map and Ring memory kinds with a map-kind property; `Ring` framing; the pointer-free predicate and its `Check` finding; declared `Limits`; and a BTF emitter over `StructDescriptor` arrays with a reader that checks its own output. Nominal coverage first, in the same pass as step 9's alias layer; the leaf tables and the `BpfProgram` root are Fidelity.Platform's and Composer's. Spec: 11, Composer `ebpf-targeting/02` and `03`. Closes: the ThreeBody row in §2.

Steps 1, 5, and 8 have no prerequisites and can run in parallel. Steps 2–4 are one lane. Steps 9–10 are one lane after 8. Steps 11 and 12 follow 9 and can run in parallel; step 16 rides with 9. The §7.3 question stays open and stays first among the design questions; step 5 is where it is exercised.

## 5. Rules for the work

- Shared code is module functions in the intersection subset: positional DU payloads; at least two cases per DU; no nested patterns at match sites; no if-expressions in argument position; cross-module values as `[<Literal>]` only; no interfaces. These are WrenHello findings 4–7 and Conclave's W-02 discipline, and they are what makes one file compile under Fable, .NET, and Composer.
- No BCL in implementation: no `Guid`, `BitConverter`, `DateTimeOffset`, `Span`, reflection. The design documents' samples are read for design, not copied.
- Every type that crosses into Fidelity.Platform clears the DU-import wall: string-aliased tags with constant modules until the cross-assembly DU layout path is fixed.
- Recover before rewriting: the encoder is in history; the envelope and F# primitives are in `Conclave.Wire`; the extraction machinery is in `PlatformPinResolution.fs`; the `MemoryRegionDef` shape is in `FrontEnd/Templates/`.
- Platform's framing (RFC 6455) and BAREWire's framing (the envelope inside the payload) are two layers; neither absorbs the other.
- `tests/Platform/Providers/` tests a rejected design; it is retired, not repaired.
