# The Intersection Subset and the Build Gates

BAREWire's shared tiers compile from one source under three compilers: Fable (JavaScript), .NET, and Composer (Clef to native). The Readiness Audit §5 states the discipline in general terms; this note records the specific rules the 2026-09-03 rebuild verified against the Composer snapshot pinned by HelloProof (`v0.0.2+9a1a60b1`), the evidence for each, and the gates that enforce them. Rules marked *verified* were established by a reachable program compiled to a native binary and run; rules marked *documented* come from WrenHello's `docs/composer-findings.md` and Composer's `docs/CCS_Clef_Feature_Audit.md`.

The subset is a property of the current compiler build, not of the language. Clef has lists, `for` loops, mutable record fields, and nested patterns; the pinned build's front end does not yet expose some of them to user source, and its middle end lacks witnesses for others. Each rule below names the construct that replaces it today and the *preferred spelling* once the surface lands, so the migration back is a mechanical edit and not a redesign. Every code site that bends to a rule carries a comment of the form `SUBSET(<rule>)` naming the preferred spelling; `grep -rn "SUBSET(" src/` lists the debt.

**Later on 2026-09-03:** the compiler lane's rebuilt Composer (the uncommitted Composer and clef working trees; `dotnet build src/Composer.fsproj -c Debug` in `~/repos/Composer`) closes every rule marked *closed* below. The evidence is in §6: 103 repro programs compile and print correct values with it, `samples/RoundTrip` runs and its transcript is byte-identical to `expected.txt`, and HelloProof's obligations are unchanged. The `SUBSET(...)` sites keep their subset form until HelloProof re-snapshots that compiler; the *Status* column names both compilers. Three rules were withdrawn by the same lane: re-verified in isolation, the construct lowers on the snapshot and the reported failure was a cascade of another gap. `~/repos/Composer/docs/Surface_Gaps_2026-09.md` holds the root cause and fix of each closed rule by file and line.

Rule ids: `generalization`, `array-length`, `record-literal-missing-field`, `string-indexer`, `string-constant`, `string-equality`, `string-to-bytes`, `array-length-in-array-returning-function`, `option-argument`, `record-array-literal`, `record-arrays`, `recursive-union`, `three-case-match`, `string-payload`, `module-union-value`, `option-payload-shared`, `record-inference`, `bits-word`, `platform-word`, `u-literal`, `single-payload`, `nested-pattern`, `two-cases`, `no-interfaces`, `immutable-records`, `record-union-field`, `literal-values`, `string-tags`, `no-map`, `arrays`, `no-failwith`, `no-sprintf`, `array-intrinsics`, `value-match`, `if-argument`, `while`, `generic-option`, `short-circuit`, `apostrophe-name`, `shadowed-abbreviation`, `record-short-name`, `generic-record-field`, `string-length-unit`.

## 3. Encoding conventions that follow from the rules

- A writer is `byte array -> int -> 'a -> int`: bytes, offset, value, next offset.
- A reader is `byte array -> int -> 'a * int`: bytes, offset, value and next offset.
- `Cursor.Fault` (`-1`) is the fault offset. It propagates: any operation given a fault offset returns one. A codec is composed straight through and checked once.
- A stream decode has three outcomes: the frame and its consumed length, `Envelope.Incomplete` (`-2`, read more and retry), or `Cursor.Fault` (a whole frame is present and malformed; do not retry).
- Capacity is declared, not grown. `Codec.encode capacity write value` returns the bytes and their length, or `Cursor.Fault`, when the value does not fit; the declaring authority is the buffer schema in the platform description.
- Sequences are arrays. `Fmt.join` and every table in the schema and platform tiers take `X array`.

## 4. Substrate shims

The Encoding tier needs two things the substrates provide differently: UTF-8 text and IEEE-754 bit casts. Each project file lists one shim per concern; nothing is selected at run time (docs/07).

| Concern | Composer (`BAREWire.fidproj`) | .NET (`BAREWire.fsproj`) | Fable (`BAREWire.Fable.fsproj`) |
| --- | --- | --- | --- |
| `Text.toUtf8`, `Text.ofUtf8` | `Substrate/Text.Clef.fs`: `String.toBytes`, `String.fromBytes` (identity views) | `Substrate/Text.Utf16.fs`: hand-written transcoding | same file as .NET |
| `Float.f32ToBits` etc. | `Substrate/Float.Clef.fs`: `Bits` intrinsics | `Substrate/Float.Dotnet.fs`: pointer reinterpretation (docs/99 §3.2) | `Substrate/Float.Fable.fs`: `DataView` |

`String.length` is the substrate's unit (`string-length-unit`): UTF-8 bytes on Clef, UTF-16 code units on .NET and JavaScript, so `String.length "héllo"` is 6 natively and 5 elsewhere. The Encoding tier never sizes a string by it (`Text.toUtf8` measures the bytes it writes) and the transcript does not print it; a shared tier that needs a character count needs a shim, not `String.length`.

## 5. The gates

Layout derivation returns `Result<StructDescriptor, LayoutFinding array>`. A consumer
must handle `Error` before using offsets for a memory view, BTF, or proof. Validation
reports `extent-overflow` when exact byte arithmetic cannot be represented by the
hosted descriptor; its `ExpectedSize` is then `None`, never a wrapped size. `Abi.tryAlignUp`
and `Abi.tryFieldSize` likewise return an option. This implementation limit does not
define a Clef source-level numeric width. The RoundTrip sample handles derivation
failure explicitly and exits unsuccessfully.

Representation bounds are checked as exact plain decimal text: an optional sign,
digits, and an optional fractional part. Integer representations require integer
text, unsigned ranges cannot include negatives, and the lower bound cannot exceed
the upper bound. Malformed text is a finding, not an unbounded or rounded range.
Contract manifests include `floor` and `atmost` whenever a return bound is declared,
so changing a fact read by saturation changes the observer's output too.

The permanent .NET and JavaScript regressions exercise these boundaries. The JavaScript
proof gate fails if cvc5 cannot be dispatched; a skipped solver is not proof evidence.
These hosted gates do not replace the native RoundTrip acceptance gate below.

A `[compilation] target = "library"` compile demotes every type error in unreachable code to an informational message, so it is a weak check: a library with no entry point is all unreachable code. The gate that counts is a reachable program compiled to a native binary and run.

| Gate | Command | What it proves |
| --- | --- | --- |
| Native | `Composer compile samples/RoundTrip/RoundTrip.fidproj` then run `targets/roundtrip` | Every shared tier lowers and runs on the Clef substrate; the sample's output is the golden transcript. **Status 2026-09-03:** passes on the rebuilt Composer (the Composer and clef working trees): the 27 transcript lines are identical to `expected.txt`. Blocked on the pinned snapshot by `array-length`, `generalization`, `recursive-union`, `record-arrays`, `string-constant`, `string-equality`, and `short-circuit`. The .NET and JavaScript gates are the must-pass gates; native is the acceptance gate on the rebuilt compiler until HelloProof re-snapshots it. `samples/RoundTrip/Main.clef` is the acceptance program; its stdout is diffed against `samples/RoundTrip/expected.txt`, which `tests/TranscriptTests.fs` produces and re-checks through the .NET build. |
| .NET | `dotnet build src/BAREWire.fsproj` and `dotnet run --project tests/BAREWire.Tests.fsproj` | The tiers compile under .NET; the golden-frame corpus and the validator verdicts hold. |
| JavaScript | `fable src/BAREWire.Fable.fsproj --outDir <dir>`, `echo '{"type":"module"}' > <dir>/package.json`, then `node tests/js/roundtrip.mjs <dir>` and `node tests/js/tiers.mjs <dir>` | All six tiers compile under Fable with the JavaScript shims; the emitted code produces the golden bytes, validates and emits a schema, derives and validates a layout, reads back its own BTF, and declares the Linux description whose obligations it hands to cvc5 (`unsat` on each). |
